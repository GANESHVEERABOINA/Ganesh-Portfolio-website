# 🚀 Ganesh Veeraboina | AWS DevOps Engineer Portfolio

Welcome to the repository of my personal portfolio website! This project is a highly interactive, 3D-integrated, monochromatic single-page application (SPA) designed to showcase my skills, experience, and projects as an AWS DevOps Engineer.

### 🌐 **Live Demo:** [Click Here to View Portfolio](https://ganeshveeraboina.github.io/Ganesh-Portfolio-website/)

---

## ✨ Key Features

Unlike a traditional static portfolio, this website is built with a "Hacker/Enterprise" aesthetic, featuring:

*   🖥️ **Terminal 'About Me':** A custom command-line interface design that prints my background using terminal semantics (`> cat about_me.txt`).
*   🕸️ **Interactive 3D Skill Network:** A fully interactive, parallax-driven 3D radial network map built with Framer Motion. It visually maps my DevOps toolchain (AWS, Docker, K8s, Jenkins, Terraform) floating in 3D space, which rotates based on mouse movement.
*   ⚙️ **Live CI/CD Architecture Flow:** A dynamic blueprint-style diagram representing an end-to-end Enterprise Deployment Pipeline, complete with active status indicators.
*   🌌 **Premium Monochromatic UI:** A strict black, white, and glass-glow design system for a clean, modern, and developer-focused user experience.
*   📱 **Fully Responsive:** Seamlessly adapts from a desktop 3D experience to a mobile-friendly accordion tree layout.

---

## 🛠️ Tech Stack

This project is built using modern web development technologies to ensure high performance and smooth animations:

*   **Framework:** React 18
*   **Build Tool:** Vite
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS
*   **Animations:** Framer Motion (for 3D transforms, spring physics, and parallax tracking)
*   **Icons:** Lucide React
*   **Deployment:** GitHub Actions & GitHub Pages

## 💻 Local Development

Follow these steps to set up the project locally on your machine.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v16 or higher recommended).

### 1. Clone the repository
```bash
git clone [https://github.com/GANESHVEERABOINA/Ganesh-Portfolio-website.git](https://github.com/GANESHVEERABOINA/Ganesh-Portfolio-website.git)
cd Ganesh-Portfolio-website

### 2. Install dependencies
Bash
npm install

###3. Run the development server
Bash
npm run dev
Open your browser and navigate to http://localhost:5173 to see the app in action.

📦 Building for Production
To create a production-ready build:

Bash
npm run build
This will generate an optimized dist folder.
