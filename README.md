## ✨ Key Features (Hacker / Enterprise Edition)

Unlike a traditional static portfolio, this website is built with a custom **monochromatic glass-glow aesthetic**, featuring:

* 🖥️ **Terminal 'About Me':** A custom command-line interface design that prints my background using terminal semantics (`> cat about_me.txt`).
* 🕸️ **Interactive 3D Skill Network:** A fully interactive, parallax-driven 3D radial network map built with Framer Motion. It visually maps my DevOps toolchain floating in 3D space, which rotates based on mouse movement.
* ⚙️ **Live CI/CD Architecture Flow:** A dynamic blueprint-style diagram representing an end-to-end Enterprise Deployment Pipeline, complete with active status indicators.
* 🌌 **Premium Monochromatic UI:** A strict black, white, and glass-glow design system for a clean, modern, and developer-focused user experience.
* 📱 **Fully Responsive:** Seamlessly adapts from a desktop 3D experience to a mobile-friendly accordion tree layout.

## 💻 Local Development & Setup

Follow these steps to set up the project locally on your machine.

**Prerequisites:** Make sure you have [Node.js](https://nodejs.org/) installed (v16+ recommended).

```bash
# 1. Clone the repository
git clone [https://github.com/GANESHVEERABOINA/Ganesh-Portfolio-website.git](https://github.com/GANESHVEERABOINA/Ganesh-Portfolio-website.git)
cd Ganesh-Portfolio-website

# 2. Install all required dependencies
npm install

# 3. Start the local development server
npm run dev
